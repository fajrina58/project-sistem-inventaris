# 📚 Kala & Kata - Sistem Inventaris Buku

"Kala & Kata" adalah aplikasi berbasis web yang dikembangkan menggunakan **Laravel** untuk mengelola data dan manajemen inventaris buku secara praktis dan terstruktur.

---

## ✨ Fitur Utama
* 📖 **Pendataan Buku:** Menambahkan, mengubah, dan menghapus data buku (judul, penulis, kategori, stok, dll).
* 🗂️ **Manajemen Kategori:** Mengelompokkan buku berdasarkan kategori tertentu.
* 👤 **Autentikasi Pengguna:** Sistem login dan manajemen hak akses pengguna.
* 🔍 **Pencarian & Filter:** Memudahkan pencarian buku berdasarkan judul atau kategori.

---

## 🛠️ Teknologi yang Digunakan
* **PHP** (Laravel Framework)
* **MySQL** (Database via phpMyAdmin / XAMPP)
* **Git & GitHub** (Version Control)
* **VS Code** (Code Editor)
